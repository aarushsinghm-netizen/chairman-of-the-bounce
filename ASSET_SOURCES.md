# Asset sources

All character, prop, terrain, icon, font and audio assets are downloaded. No AI-generated art or audio is used. Plain UI panels, the power meter, text layout and paper lines are drawn in code. Original game code and assembly were made with OpenAI Codex assistance.

Seven source collections from six credited creator groups are used. Asset quality/style mismatches are intentional. These assets are published for reuse; they are not ripped from commercial games.
